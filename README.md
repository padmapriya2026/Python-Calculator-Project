# Python Calculator Project

## Project Description
This is a menu-based calculator developed using Python. It performs basic mathematical operations and handles invalid inputs.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Square
- Square Root
- Input validation and error handling

## Technologies Used
- Python

## How to Run
1. Install Python on your computer.
2. Open the terminal or command prompt.
3. Navigate to the folder containing `calculator.py`.
4. Run the command:

```bash
python calculator.py
```
